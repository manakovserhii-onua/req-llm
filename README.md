# Аналіз вимог до ПЗ з використанням великих мовних моделей: від неформальних описів до UML-моделей і трасування вимог

Матеріали відтворення експериментів статті:
С.Ю. Манаков, О.Г. Трофименко, Ю.Г. Лобода, Н.І. Логінова, П.О. Чикунов.
*Аналіз вимог до програмного забезпечення з використанням великих мовних моделей: від неформальних описів до UML-моделей і трасування вимог* // Проблеми програмування (подано, 2026).

*Replication package for an article on LLM-based requirements analysis (requirements → UML use case and class models → traceability). Prompts, raw model outputs, reference (gold) models and evaluation scripts.*

## Відтворення

Потрібен Python 3.10+.

```bash
pip install -r requirements.txt
python scripts/evaluate_e1.py      # -> E1_PROMISE/результати_E1.csv, .md
python scripts/evaluate_e2.py      # -> E2_Кейс/результати_E2.csv
python scripts/fig5.py             # рис. 5
```

Перевірка синтаксису PlantUML у `evaluate_e2.py` виконується лише за наявності Java і `plantuml.jar`
(шлях задається змінною середовища `PLANTUML_JAR` або файлом `scripts/plantuml.jar`, який до репозиторію не входить).

Прогони моделей виконувалися вручну через вебінтерфейси чат-асистентів (ChatGPT, Claude) за протоколом,
описаним у статті; кожна конфігурація прогонялася двічі.
